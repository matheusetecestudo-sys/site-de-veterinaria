# VidaPet - Clínica Veterinária Premium | 🐾

Esta é uma landing page de alta performance e luxo para a clínica **VidaPet**, desenvolvida com React, Vite e Tailwind CSS. O projeto foi transformado de uma clínica estática para uma clínica veterinária premium com foco em acolhimento, tecnologia e cuidado animal.

## 🌟 Diferenciais desta Versão

- **Paleta de Cores Nichada:** Utiliza tons de Verde Floresta (confiança) e Âmbar (acolhimento), eliminando completamente tons de azul e rosa.
- **Design de Alta Performance:** Imagens em alta definição geradas por IA para representar o ambiente clínico moderno.
- **Convertion-Oriented:** Foco total em agendamento via WhatsApp e facilidade de contato.
- **Experiência Visual:** Animações fluidas com Framer Motion (Motion API) e design mobile-first refinado.

## 🚀 Como implantar na Vercel

O projeto já está preparado para implantação automática na Vercel. Siga os passos abaixo:

1. **Conecte seu repositório:** No painel da Vercel, clique em "Add New" -> "Project" e selecione o seu repositório do GitHub.
2. **Configurações de Build:** A Vercel detectará automaticamente o Vite.
   - **Framework Preset:** `Vite`
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
3. **Deploy:** Clique em "Deploy" e suas transformações estarão no ar!

## 🛠️ Tecnologias Utilizadas

- **React 19**
- **Vite 6**
- **Tailwind CSS 4**
- **Motion (Framer Motion)** para animações sofisticadas
- **Lucide React** para ícones de alta qualidade
- **Imagens Geradas por IA** para um visual único e exclusivo

## 📄 Estrutura do Projeto

- `src/App.tsx`: Componente principal contendo toda a lógica e seções da clínica.
- `src/index.css`: Sistema de design (Design System) com variáveis de cores e tokens.
- `public/images/`: Assets visuais da clínica veterinária.
- `vercel.json`: Garantia de roteamento para SPAs.
